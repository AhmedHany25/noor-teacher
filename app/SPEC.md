# نور القرآن — أداة المعلم: مواصفات النسخة ١

هذا الملف هو المرجع الذي نبني عليه. أي ميزة غير مذكورة هنا ليست في النسخة ١.
تم الاتفاق على كل البنود في جلسة grill-me بتاريخ 2026-11-27.

## الهدف

أداة شخصية لمعلم قرآن تدير الطلاب والحلقات والحضور والمستحقات من اللاب أو الموبايل،
تعمل بدون إنترنت، وتُثبَّت على الموبايل كتطبيق. مجانية التشغيل. قابلة للتوسع لاحقًا لأكثر من معلم.

## الأساس التقني

| البند | القرار |
|---|---|
| الواجهة | React + TypeScript + Vite، داخل `app/` في نفس الريبو |
| البيانات | Cloud Firestore مع التخزين المحلي بدون إنترنت (persistent local cache). لا localStorage كمصدر بيانات |
| الدخول | Google Sign-In فقط. بيانات كل معلم تحت `users/{uid}` |
| التثبيت | PWA (manifest + Service Worker عبر vite-plugin-pwa) |
| الاستضافة | Firebase Hosting (الخطة المجانية) |
| الاختبارات | Vitest للمنطق والمكونات، Playwright لاختبارات المتصفح. كل ميزة تُبنى بـ TDD |
| الواجهة | عربي فقط، RTL، أرقام هندية (١٢٣)، تواريخ ar-EG، أخضر زمردي، وضع ليلي تلقائي |

القاعدة الهندسية: **منطق الحساب (المواعيد، المستحقات، التعويضات) دوال TypeScript نقية في `src/domain/`** بلا React ولا Firebase،
ولكل دالة اختبارات. الواجهة وطبقة Firestore تستدعيها فقط.

## نطاق النسخة ١

### ١. الطلاب
- الحقول: الاسم، رقم واتساب ولي الأمر، البلد (منطقة زمنية)، جهة الدفع (أكاديمية واحدة أو «خصوصي»)، سعر خاص اختياري، المستوى، العمر، ملاحظات.
- الحالة: نشط / موقوف / انقطع. الطالب لا يُحذف تلقائيًا ويبقى تاريخه.
- الصورة مؤجلة للنسخة ٢.

### ٢. الحلقات والمواعيد
- الحلقة تسمح بأكثر من طالب، والواجهة مصممة للحصة الفردية كأساس.
- ميعاد متكرر: أيام الأسبوع، لكل يوم وقته، المدة، تاريخ البداية، تاريخ نهاية اختياري.
- استثناء ليوم محدد: إلغاء (مع السبب)، نقل لتاريخ/وقت آخر، حصة إضافية.
- إيقاف الحلقة لشهر كامل.
- نوع الحصة: عادية، تعويض (مجانية)، تجريبية (مجانية).
- كل المواعيد بتوقيت المعلم، ويُعرض بجانبها الوقت عند الطالب.

### ٣. الحضور
- لكل طالب في الحصة: حضر / غاب / اعتذر.
- الغياب والاعتذار: يحدد المعلم في كل مرة هل يُحتسب في المستحقات.
- المدة الفعلية اختيارية؛ إن لم تُكتب تُستخدم مدة الحلقة.
- الإلغاء يُسجَّل سببه: «ألغاه الطالب» أو «ألغيته أنا». إلغاء المعلم يضيف تلقائيًا **تعويضًا مستحقًا** للطالب، وتُربط حصة التعويض به عند تنفيذها.
- يمكن تسجيل أو تعديل أو مسح الحضور لأي يوم سابق.

### ٤. الأكاديميات والمستحقات
- لكل أكاديمية: الاسم، **العملة**، طريقة الحساب الافتراضية (بالحصة / بالساعة / بالشهر) وسعرها.
- الطالب يرث طريقة أكاديميته، ويمكن أن يكون له سعر/طريقة خاصة.
- الطلاب الخصوصي بالعملة الأساسية للمعلم.
- الإجماليات تُعرض لكل عملة على حدة دون تحويل.
- بالشهر: المبلغ كامل إذا تمت حصة واحدة على الأقل في الشهر، ولا شيء إذا كانت الحلقة موقوفة الشهر كله. لا تقسيم على الأيام.
- التعويض والتجريبية لا يُحتسبان.
- كشف شهري (شهر ميلادي) لكل أكاديمية.
- عدّاد الدورة لكل طالب (الهدف الافتراضي ٨، قابل للتعديل) يتصفّر عند تسجيل استلام راتب.
- تسجيل المبالغ المستلمة (الجهة، المبلغ، العملة، التاريخ، ملاحظة)، وعرض المتبقي لكل جهة = المستحق − المستلم.

### ٥. الشاشات
- **اليوم**: حصص اليوم بالترتيب، تسجيل الحضور بضغطة، وقت الطالب، عدّ تنازلي للحصة التالية، تنبيه بالحصص الفائتة غير المسجلة.
- **مراجعة**: الحصص غير المسجلة خلال آخر ٦٠ يومًا.
- **الطلاب**، **الحلقات**، **الأكاديميات والمستحقات**، **الإعدادات**.

### ٦. البيانات
- استيراد ملف النسخة الاحتياطية من الموقع القديم (`{app, v, db}` أو `db` مباشرة) مرة واحدة، مع ملخص قبل الحفظ (عدد الطلاب، الحلقات، سجلات الحضور، المدفوعات). الموقع القديم لا يُمس.
- خطط الحفظ والتقدم وعلامات المصحف تُستورد وتُخزن كما هي (`legacy`) دون عرض حتى النسخة ٢.
- تصدير نسخة احتياطية JSON من الإعدادات.
- كشف الأكاديمية: نص جاهز للواتساب + ملف Excel.

## خارج النسخة ١

- **النسخة ٢:** تقرير ولي الأمر بعد الحصة، الواجبات، سجل الأخطاء، خطط الحفظ والتقدم، صور الطلاب.
- **النسخة ٣:** المصحف، الألعاب، الإشعارات والتطبيق مغلق (مسار مجاني: مهمة مجدولة على GitHub Actions أو Cloudflare Workers + FCM).

## شكل البيانات في Firestore

كل المسارات تحت `users/{uid}`. قواعد الأمان: المستخدم يقرأ ويكتب تحت `uid` الخاص به فقط.

```ts
// users/{uid}
type Profile = {
  name: string;
  baseCurrency: string;      // عملة الطلاب الخصوصي، افتراضيًا "جنيه"
  timeZone: string;          // توقيت المعلم، مثل "Africa/Cairo"
  cycleTarget: number;       // هدف عدّاد الدورة، افتراضيًا 8
  theme: 'auto' | 'light' | 'dark';
  importedAt?: number;       // وقت استيراد البيانات القديمة
};

type PayMode = 'session' | 'hour' | 'month';

// users/{uid}/academies/{academyId}
type Academy = {
  name: string;
  currency: string;
  payMode: PayMode;
  rate: number;              // سعر الحصة أو الساعة أو الشهر
  archived: boolean;
};

// users/{uid}/students/{studentId}
type Student = {
  name: string;
  guardianPhone?: string;
  timeZone?: string;         // فارغ = نفس توقيت المعلم
  academyId: string | null;  // null = خصوصي
  payMode?: PayMode;         // يتجاوز طريقة الأكاديمية
  rate?: number;             // يتجاوز سعر الأكاديمية
  level?: string;
  age?: number;
  notes?: string;
  status: 'active' | 'paused' | 'left';
  createdAt: number;
};

// users/{uid}/groups/{groupId}
type Group = {
  name?: string;             // فارغ = يُشتق من أسماء الطلاب
  studentIds: string[];
  startDate: string;         // "YYYY-MM-DD"
  endDate?: string;
  slots: { weekday: 0|1|2|3|4|5|6; time: string }[]; // time = "HH:mm"، weekday 0 = الأحد
  durationMin: number;
  pausedMonths: string[];    // ["YYYY-MM"]
  exceptions: Record<string /* YYYY-MM-DD */, GroupException>;
  archived: boolean;
};
type GroupException =
  | { type: 'cancel'; by: 'student' | 'teacher' }
  | { type: 'move'; toDate: string; toTime: string }
  | { type: 'extra'; time: string; kind: 'regular' | 'makeup' | 'trial'; makeupFor?: string };

// users/{uid}/sessions/{groupId}_{YYYY-MM-DD}  — سجل حصة تمّت أو أُلغيت
type Session = {
  groupId: string;
  date: string;
  time: string;
  kind: 'regular' | 'makeup' | 'trial';
  actualDurationMin?: number;
  attendance: Record<string /* studentId */, { status: 'p' | 'a' | 'e'; billable: boolean }>;
  makeupFor?: string;        // معرّف الحصة الملغاة التي يعوّضها
  note?: string;
  updatedAt: number;
};

// users/{uid}/payments/{paymentId}
type Payment = {
  payer: { type: 'academy'; academyId: string } | { type: 'student'; studentId: string };
  amount: number;
  currency: string;
  date: string;
  resetsCycle: boolean;      // تصفير عدّاد الدورة لطلاب هذه الجهة
  note?: string;
};

// users/{uid}/legacy/{plans|progress|marks}  — بيانات النسخة القديمة كما هي
```

التعويضات المستحقة لا تُخزن كحقل منفصل؛ تُحسب من الاستثناءات (`cancel` بواسطة `teacher`)
ناقص الحصص التي لها `makeupFor`. هكذا لا يمكن أن يختلف العدّاد عن الواقع.

## قرارات تبسيط أثناء البناء

- توقيت المعلم يُؤخذ من الجهاز تلقائيًا بدل إعداد يدوي.
- الأكاديمية: الاسم والعملة وطريقة الحساب والسعر فقط (بدون هاتف وملاحظات).
- الأكاديميات تحت تبويب «المستحقات»، والكشف الشهري سيظهر في نفس الشاشة.
- نموذج الطالب يعرض الأساسيات فقط، والمستوى والعمر والسعر الخاص والملاحظات تحت «تفاصيل إضافية».
- الحلقة تُنشأ بالطلاب والأيام ووقت كل يوم والمدة؛ الاسم اختياري.
- الحضور: الحصة الفردية تُسجَّل بضغطة من «اليوم»؛ الحصة الجماعية وتفاصيل أي حصة (المدة الفعلية، الإلغاء، النقل) من صفحة الحصة.
- الاحتساب الافتراضي: الحضور والغياب يُحتسبان، والاعتذار لا يُحتسب؛ يمكن تغييره لكل طالب من صفحة الحصة.
- إلغاء الحصة أو نقلها يمسح أي حضور مسجل لها.
- تنبيه «حصص فاتت من غير تسجيل» يعدّ الأيام السابقة فقط، وشاشة المراجعة تعرض آخر ٦٠ يومًا مجمّعة حسب اليوم.
- المستحقات: كل طالب خصوصي جهة دفع مستقلة (أسرته تدفع)، وطلاب الأكاديمية يتجمعون تحتها. المتبقي = كل المستحق منذ البداية − كل المستلم.
- مبلغ مستلم من أكاديمية يمكن تعليمه «راتب الدورة» فيبدأ عدّاد الحصص (الهدف ٨) من جديد. الطالب الخصوصي بلا عدّاد.
- عملة الطلاب الخصوصي «جنيه» حاليًا حتى نضيف إعداد العملة الأساسية.
- «Excel» يحمّل ملف CSV بترميز يفتحه Excel بالعربي، بدل مكتبة xlsx (أخف وبدون ثغرات).
- الاستيراد يقبل ملف الموقع القديم (`db` خام أو `{app, v, db}`) ونسخ التطبيق الجديد، ويحتفظ بنفس المعرّفات فتكرار الاستيراد لا يكرر البيانات.
- تحويل البيانات القديمة: سعر الأكاديمية = أكثر سعر شائع بين طلابها، والمختلف يصبح سعرًا خاصًا للطالب؛ الحصة الواحدة تصبح حلقة بيوم واحد؛ الغياب/الاعتذار يُحتسب فقط لو كان معلَّمًا «مدفوع» قديمًا؛ الإلغاء «المدفوع» يصبح اعتذارًا محتسبًا؛ الشهر المعلَّم «مدفوع» يصبح مبلغًا مستلمًا بقيمة مستحق ذلك الشهر. الصور والأيقونات لا تُنقل.

## ترتيب البناء

1. هيكل المشروع + PWA + الاختبارات + النشر الأول.
2. الدخول + طبقة Firestore.
3. الطلاب.
4. الأكاديميات.
5. الحلقات والمواعيد (منطق `occurrences` مع اختباراته).
6. الحضور + شاشة اليوم + المراجعة.
7. المستحقات والكشوف والمبالغ المستلمة.
8. الاستيراد والتصدير.
